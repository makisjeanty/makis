# UI/UX Design System para Trilhas de Cursos

Esta skill define o padrão de design visual para as páginas de **Trilhas de Aprendizado Interativas** (estilo mapas de progressão modernizados / gamificados em tom Warm-Dark).

## 🎨 Princípios Estéticos

1. **Caminho Conector Serpenteado Moderno**:
   - Usar nós circulares/hexagonais elevados com luz sutil (*glow*) em estado ativo (`--accent`).
   - Linha conectora com gradiente vertical dinâmico (não apenas uma linha sólida simples).
   - Card de Módulo atuando como "Marco de Conquista" (Milestone Header), separando visualmente as fases.

2. **Hierarquia Clara de Conteúdo**:
   - Indicador de tempo e tipo da lição (Teoria, Quiz, Desafio de Código).
   - Status do nó: **Concluído (Verde Emerald)**, **Em Andamento (Terracota com Pulse)** e **Bloqueado (Vidro Escuro + Cadeado Fechado)**.

3. **Painel Lateral de Progresso / Drawer**:
   - Resumo do progresso total em porcentagem (ex: `45% concluído`).
   - Estatísticas de lições finalizadas vs restantes.
